# Change Log

All notable changes to the Reqly extension are documented here.

## [0.1.0]

First working release: a single request panel that speaks HTTP for real.

### Added

- Request panel with method, URL, query parameters, headers, body and authentication.
- All seven HTTP methods, plus JSON, XML, text, URL-encoded, multipart and binary bodies.
- Bearer, Basic and API key authentication.
- Response inspector with status, timings, size, syntax highlighting, headers, image preview and a
  timing waterfall.
- cURL import by pasting into the URL field, and "Copy as cURL" from the send menu.
- Per-request settings for timeout, redirect following and TLS verification.
- Activity bar view with the Reqly mascot as the entry point.
- Reqly design system palette, following the editor's light and dark theme.
